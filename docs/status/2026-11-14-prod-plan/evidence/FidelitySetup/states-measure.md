## 1280x720 시안(C6-empty, C6-loading, C6-error, C7-saving)
- 이 시안 4장은 2560x1440 = 1280x720 dp 캔버스라서 위쪽 여백이 작은 화면 값(ui-spec 56/40)이다. 시안 헤더 y=67, 제목 y=176, 부제 y=248. 앱의 1280 렌더는 차량 기준 80/64를 그대로 쓰므로 헤더 y=86, 제목 y=211(+19, +35). 차량 설계 기준은 1600x900 dp(작업 지시)이므로 이 작은 화면 여백은 적용하지 않았다.
- 1600 시안이 없는 상태라서 내용 기준 비교 대신 같은 요소 안쪽 간격으로 비교했다(1280 시안/앱 모두 dp로 환산).

| 상태 | 요소 | 시안(제목 대비 y) | 앱(제목 대비 y) | 차이 |
|---|---|---|---|---|
| C6-empty | 아이콘 | 199 | 141 | -58 |
| C6-empty | 빈 상태 제목 | 264 | 205 | -59 |
| C6-empty | 빈 상태 설명 | 318 | 270 | -48 |
| C6-loading | 로딩 문구 | 165 | 150(앱은 스켈레톤 3줄과 한 밴드) | 비교 불가 |
| C6-error | 오류 제목 | 169 | 141 | -28 |
| C6-error | 오류 설명 | 252 | 206 | -46 |
| C6-error | 다시 시도 버튼 | 337 | 288 | -49 |

위 간격 차이는 이번 PR에서 고치지 않았다. 이유: 시안의 빈 상태·오류 패널이 제목 아래에서 시작하는 위치(제목+약 200 dp)가 1280 캔버스 값이고, 1600 시안이 없어 1600 기준의 정답 수치를 알 수 없다.

## 확인 창(C6-delete, C7-unpair, C7-withdraw)
- Paparazzi 스냅샷에 확인 창을 띄운 케이스가 없어 앱 쪽 측정값이 없다. 시안은 축소 이미지에서 눈으로 잰 근사값만 있다: 창 폭 약 740~760 dp, 가운데 정렬. 버튼 높이와 안쪽 여백은 정확히 재지 못했다.
- 앱 ConfirmDialog 코드 값: 폭 상한 768 dp, 버튼 104 dp, 안쪽 여백 32 dp. 렌더 측정은 못 했으므로 일치한다고 쓰지 않는다.
